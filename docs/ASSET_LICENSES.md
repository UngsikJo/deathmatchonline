# 에셋 출처

현재 외부 이미지·캐릭터·타일·아이콘·효과음 파일을 포함하지 않았습니다. 도트 캐릭터와 경기장은 프로젝트 코드(`apps/web/src/game/fighterArt.ts`, `stageArt.ts`)가 실행 시 직접 생성하는 자체 제작물입니다.

웹 글꼴은 운영체제 기본 글꼴로 표시합니다. PRD의 Kenney·0x72·Game-icons 후보를 채택할 때 아래 표에 실제 다운로드한 파일 기준으로 기록합니다.
