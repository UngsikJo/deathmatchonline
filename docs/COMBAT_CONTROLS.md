# 공통 조작·방어·궁극기 게이지 명세

- 작성일: 2026-11-06, 한국 시간
- 상태: **세부 규칙 초안 — UI 목업의 참고 명세로 `feature/lobby-ui`에 공유, 게임 구현 전**
- 사용자 지정: A 웅크려 막기, S 대시, D 기본 공격, F 쓰러진 상대 공격, Q/W/E 기본 스킬 1/2/3, R 궁극기
- 사용자 지정: 공격 성공·받은 피해로 궁극기 게이지 충전, 100%에서 궁극기 활성화
- 검수할 세부안: 다운 유발 기술·지속·기상·추가 공격 제한, 방어 수치, 게이지 계수·초기화·소비 규칙
- 연결 문서: [캐릭터 4종](CHARACTERS.md), [PRD](PRD.md), [구조](ARCHITECTURE.md)

현재 코드는 이전의 단일 임시 키 배치와 R 쿨다운을 사용합니다. 이 문서는 새 키와 게이지를 구현할 수 있도록 정리한 변경 명세이며, 이번 문서 작업에서 게임 로직을 변경하지 않습니다.

## 1. 공통 키 배치

| 키   | 고정 역할      | 입력 방식                     | 캐릭터별 차이                                   |
| ---- | -------------- | ----------------------------- | ----------------------------------------------- |
| ↑↓←→ | 이동·방향 조준 | 누르는 동안 이동              | 첫 초안은 기본 속도 동일                        |
| A    | 웅크려 막기    | 누르고 유지, 놓으면 해제      | 첫 초안은 방어 규칙 동일, 자세·표현 차이        |
| S    | 대시           | 누른 순간 1회                 | 이동 거리·표현·쿨다운 차이                      |
| D    | 기본 공격      | 누른 순간 1회                 | 주먹·검격·화살·마력탄                           |
| F    | 다운 추가 공격 | 누른 순간 1회                 | 다운 상태인 상대에게 각 무기·마법으로 추가 공격 |
| Q    | 기본 스킬 1    | 누른 순간 1회                 | 캐릭터 고유 효과                                |
| W    | 기본 스킬 2    | 누른 순간 1회                 | 캐릭터 고유 효과                                |
| E    | 기본 스킬 3    | 누른 순간 1회                 | 캐릭터 고유 효과                                |
| R    | 궁극기         | 게이지 100%에서 누른 순간 1회 | 캐릭터별 궁극기                                 |

스킬 바는 윗줄 Q/W/E/R, 아랫줄 A/S/D/F입니다. 공통 행동도 각 캐릭터 설명에 표시하므로 4종 × 8개 입력 항목을 문서화하되, A를 포함한 공통 동작까지 모두 서로 다른 기술이라고 표현하지 않습니다.

## 2. A — 웅크려 막기

초기 구현에서는 탑다운 시점을 유지합니다. 웅크리는 자세가 자동 회피·몸 충돌 축소·무적을 만들지는 않습니다.

1. A를 유지하면 웅크려 방어합니다. 첫 방어는 0.08초 준비 후 활성화하고, A 해제 시 즉시 종료하는 기본안입니다.
2. 방어 중에는 이동·대시·기본 공격·다운 추가 공격·Q/W/E·R을 사용할 수 없습니다. 이동 입력으로 방어 방향도 회전하지 않습니다.
3. 방어 방향은 진입 직전 바라보던 방향으로 고정합니다. 방향을 바꾸려면 A를 놓고 이동 방향을 입력한 뒤 다시 방어합니다.
4. 정면 120도에서 오는 직접 근접 공격·직선 마법·투사체의 피해를 **50% 감소**하는 초안입니다. 서 있는 상대에게 적용되는 직접 공격을 포함합니다. 다운 상태에는 A를 사용할 수 없습니다.
5. 뒤·옆의 방어 범위 밖 공격, 지면·지역 광역 공격, 데이터에 가드 불가로 명시한 기술은 감소하지 않습니다. 가드 불가 여부는 예고·설명에서 확인할 수 있게 합니다.
6. A 자체에는 별도 시간 쿨다운·방어 게이지·반격 피해를 두지 않습니다. 받는 피해가 0이 되는 완전 방어도 아닙니다.
7. 감소 뒤 소수점은 올림하고, 남은 보호막을 먼저 소비한 뒤 실제 체력을 깎습니다. 둔화·밀치기는 피해 감소만으로 제거되지 않습니다.
8. 시전·대시 중 A가 눌리면 진행 동작을 취소하지 않습니다. A 유지 의도는 기록하고 해당 동작이 끝났을 때 아직 누르는 중이면 방어 진입을 시도합니다.
9. 같은 입력 묶음에서 방어 가능한 상태의 A 유지와 다른 행동이 함께 들어오면 A를 우선하고 다른 행동은 발동하지 않습니다.
10. 키를 놓거나 창 포커스·연결을 잃으면 방어 입력을 해제합니다. 입력이 250ms 이상 갱신되지 않아도 서버에서 유지 상태를 해제합니다.

검형의 W 받아치기처럼 추가 방어 스킬이 있으면 완전 무효 판정 → A 등의 가장 큰 피해 감소율 하나 → 올림 → 보호막 → 체력 순서로 처리합니다. 최종 체력 피해만 궁극기 게이지 충전 기준이 됩니다.

## 3. S·D·F와 기본 스킬

- S는 입력 시 조준 방향으로 대시합니다. 활형도 자동으로 반대 방향으로 이동하지 않습니다. 후퇴하려면 반대 방향을 잡고 S를 누릅니다. 4종 모두 무적·벽 통과가 없습니다.
- D는 자주 사용하는 기본 공격입니다. 마우스 기본 공격과 합치거나 A에 기본 공격을 남기지 않습니다.
- 사용자가 F를 **쓰러진 상대를 공격하는 기술**로 확정했습니다. 서버가 판정한 살아 있는 다운 상대에게만 발동합니다.
- F는 대상 상태·거리·방향·벽을 발동 시와 명중 시에 확인합니다. 시전 시 대상과 다운 회차 ID를 묶어 다른 상대나 나중의 다운에 잘못 적중하지 않게 합니다. 조준 방향은 기존 규칙을 따릅니다.
- Q/W/E는 캐릭터마다 다른 기본 스킬 1/2/3입니다. 공격뿐 아니라 보호막·받아치기·둔화 지역도 포함할 수 있습니다.
- S/D/F/Q/W/E에는 캐릭터별 일반 쿨다운을 적용하고 공통 발동 간격 0.25초를 유지합니다. R은 아래의 게이지 사용 조건을 적용합니다.
- A를 제외한 키는 길게 눌러 자동 반복하지 않습니다. 준비·연속 공격 중에는 다른 행동을 겹쳐 실행하지 않습니다.

F의 대상 의미는 사용자 답변으로 확정했습니다. 아래의 지속 시간·기상·피격 제한과 다운 유발 기술은 구현을 위한 검수용 세부안입니다.

### 다운 상태와 F 판정 — 세부안

다운은 **HP가 남아 있는 쓰러짐**이며 HP 0의 KO와 구분합니다. KO는 경기 종료이고 F로 추가 타격하는 대상이 아닙니다.

| 상태                   | 초기 시간 | 가능한 행동·피격                                 |
| ---------------------- | --------- | ------------------------------------------------ |
| `standing`             | 일반 상태 | 이동·방어·행동 가능, 일반 공격의 대상            |
| `downed`               | 1.0초     | 이동·방어·대시·공격·R 불가, F만 피격 가능        |
| `recovering`           | 0.3초     | 자동 기상, 조작 잠금·모든 공격/새 상태 효과 무효 |
| 기상 완료 뒤 다운 면역 | 1.5초     | 일반 조작·피해는 정상, 다시 다운되는 효과만 거절 |

- 상태 전이는 `standing → downed → recovering → standing`입니다. 완전히 일어난 시점부터 1.5초 다운 면역을 부여합니다. 경기 시간·일반 쿨다운·기존 상태 효과 시간은 계속 흐릅니다.
- 다운은 서버가 허용한 기술의 유효 HP 피해에서 발생합니다. HP 피해가 0이거나 유효한 정면 A 방어가 성립했으면 다운을 적용하지 않습니다. 지면 공격처럼 A로 막을 수 없는 기술은 이 방어 조건을 얻지 않습니다.
- 초기 다운 유발 기술은 주먹형 E 다리 걸기, 검형 Q 찌르기, 활형 E 넘어뜨리는 화살, 마법형 Q 폭발진으로 제안합니다. 일반 밀치기·모든 공격이 자동으로 다운을 만들지는 않습니다.
- 다운되면 진행 중인 시전·대시·A 방어를 중단합니다. 이미 발사된 투사체는 유지하고, 진행 중인 연속 공격의 후속 타격은 중단합니다. 이미 소비한 일반 쿨다운·궁극기 게이지는 환급하지 않습니다.
- 이 검수안의 D/Q/W/E/R 공격은 `standing`, F는 `downed`만 대상으로 합니다. 다운 상대에게 일반 공격·기존 투사체·지역 효과가 새로 피해나 둔화를 주지 않습니다. 조건이 안 맞는 상대는 투사체 충돌 대상에서 제외하고 벽·사거리 판정은 계속합니다.
- 다운 중 F는 **다운 회차당 한 번만** 유효 적중합니다. 유효 적중 뒤 HP가 남으면 즉시 `recovering`으로 전환합니다. 보호막으로 전부 흡수해도 유효 F 기회는 소비하며, HP 피해 0이면 궁극기는 충전하지 않습니다.
- F가 없으면 1.0초 뒤 자동 기상합니다. F 적중이나 다른 공격으로 다운 시간을 연장하지 않습니다. 같은 틱의 여러 다운 원인은 하나의 회차만 만듭니다.
- 다운 면역 중 다운 기술에 맞으면 HP 피해는 정상 적용하고 다운 효과만 거절합니다. 다시 넘어뜨리는 무한 연계를 막는 초기안입니다.
- 시전자도 `standing`이며 방어·시전·대시 중이 아닐 때 F를 사용할 수 있습니다. 발동 시 살아 있는 다운 상대·현재 다운 회차·사거리·방향·벽 조건이 없으면 거절하고 F 쿨다운을 소비하지 않습니다.
- 유효하게 시작한 F가 명중 전에 기상·가림·거리 조건을 잃으면 빗나갑니다. 이미 시작한 쿨다운은 환급하지 않고 피해·궁극기 충전은 없습니다.
- 서버는 해당 틱의 만료·기상 상태를 먼저 갱신합니다. `now >= downUntil`이면 F 대상이 아니며 F 명중과 기상이 겹칠 때도 이 기준을 사용합니다. 같은 틱에 다운이 새로 발생하면 다음 유효 입력부터 F를 사용할 수 있습니다.
- 한 틱에 성립한 일반 피해는 기존 동시 판정 규칙으로 처리한 뒤 다운을 적용합니다. HP 0과 경기 종료가 다운·기상보다 우선해 쓰러짐으로 사망 결과가 취소되지 않습니다.
- F의 실제 HP 피해도 일반 피해이므로 공격자 +2%·피격자 +1% 초기 계수안을 적용합니다. 다운 발생 자체에는 별도 게이지를 주지 않습니다. 다운 중 100%가 돼도 기상·행동 잠금이 풀리기 전 R을 사용할 수 없습니다.
- 같은 경기 재접속 시 다운 회차·마감 시각·F 사용 여부·기상·면역·게이지를 서버 상태로 복원합니다. 접속 종료 동안 타이머는 진행합니다. A 유지 의도는 갱신할 수 있지만 다운/기상 중 방어는 활성화하지 않고 단발 행동을 예약하지 않습니다.
- 새 경기에는 `standing`, 모든 다운·기상·면역 시각 0, F 회차 정보 없음으로 초기화합니다.

## 4. 궁극기 게이지

### 충전 기준과 초기 계수안

게이지 충전은 클라이언트의 ‘명중했다’는 신고가 아니라 **서버가 확정한 실제 HP 감소량**으로 계산합니다. 공격이 성공해도 완전 무효·보호막으로 HP 피해가 0이면 이 초안에서는 충전하지 않습니다.

| 사건                                    | 공격자 게이지                   | 피격자 게이지                   |
| --------------------------------------- | ------------------------------- | ------------------------------- |
| D/F/Q/W/E 등 일반 공격으로 HP 피해 발생 | 실제 피해 1당 +2%               | 실제 받은 피해 1당 +1%          |
| R 궁극기로 HP 피해 발생                 | 자신의 R로는 충전하지 않음      | 실제 받은 피해 1당 +1%          |
| 완전 무효·보호막 흡수로 HP 피해 0       | +0%                             | +0%                             |
| A 방어로 일부 피해만 감소               | 감소 뒤 HP 피해를 기준으로 충전 | 감소 뒤 HP 피해를 기준으로 충전 |
| 빗나감·허공 공격·상태 효과만 적용       | +0%                             | +0%                             |
| 자해·환경 피해·경기 종료 뒤 사건        | +0%                             | +0%                             |

공격자 2%·피격자 1%는 밸런스 검수용 수치입니다. 공격에 따른 충전을 더 크게 두되 피해를 받은 쪽에도 궁극기로 대응할 기회를 주는 목적입니다. 시간 경과·방어 유지·이동만으로는 충전하지 않습니다.

### 정수 연산·피해 정산

- 내부 `ultimateCharge`는 0~10,000 정수이며 10,000이 100%입니다. 1단위는 0.01%입니다.
- 일반 공격자가 얻는 내부 값은 `actualHpDamage × 200`, 피격자는 `actualHpDamage × 100`입니다. R 공격자의 충전은 0입니다.
- 게이지는 10,000에서 멈추고 초과분은 저장하지 않습니다. 100% 미만을 반올림해서 준비 완료로 표시하지 않습니다.
- `actualHpDamage`는 피해 감소·올림·보호막 처리가 끝난 뒤 해당 타격이 실제 줄인 HP입니다. 남은 HP를 초과한 오버킬은 제외합니다.
- 다단·여러 투사체·지역 피해는 각각의 실제 피해 사건으로 처리합니다. 같은 피해 사건을 재처리하거나 스냅샷을 재수신해 중복 충전하지 않습니다.
- 한 틱의 충돌 후보를 먼저 수집한 뒤 안정적인 사건 순서로 방어·보호막·남은 HP 예산을 배분합니다. 타격별 HP 감소 합계가 틱 전 체력을 넘지 않게 합니다. 같은 틱에 이미 성립한 양쪽 공격은 함께 처리해 동시 사망 원칙을 유지합니다.

### 계산 예시

| 상황                                | 결과                                 |
| ----------------------------------- | ------------------------------------ |
| 일반 공격으로 HP 20 감소            | 공격자 +40%, 피격자 +20%             |
| 피해 20을 A로 50% 감소, 보호막 없음 | HP 10 감소, 공격자 +20%, 피격자 +10% |
| 피해 35에서 보호막 20 흡수          | HP 15 감소, 공격자 +30%, 피격자 +15% |
| 상대 HP 7일 때 일반 피해 30         | 실제 피해 7, 공격자 +14%, 피격자 +7% |
| 자신의 궁극기로 HP 20 감소          | 자신 +0%, 상대 +20%                  |
| 게이지 80%에서 일반 HP 피해 20을 줌 | 100%에서 제한, 초과 20% 이월 없음    |

### 100% 활성화와 소비

1. 서버 상태가 `active`, 본인이 살아 있는 `standing` 상태·연결 정상, 방어·대시·시전 중이 아님, 공통 행동 잠금 없음, `ultimateCharge === 10000`일 때 R을 승인합니다.
2. 100%가 되면 R을 사용할 수 있는 준비 상태를 표시합니다. 자동으로 발동하거나, 미리 누르고 있던 R을 자동 발동시키지 않습니다.
3. 유효한 R을 서버가 승인하는 순간 게이지 전부를 0으로 만들고 궁극기 시전을 시작합니다. 한 입력 처리에서 확인·소비·시작을 함께 수행합니다.
4. 100% 미만, 방어 중, 중복 입력, 이전 순번, 이미 끝난 경기 등 잘못된 R 요청은 거절하고 게이지를 소비하지 않습니다.
5. R에는 기존 20/22/24초 고정 쿨다운을 적용하지 않습니다. 다시 100%를 모아야 다음 궁극기를 사용할 수 있습니다. 다른 행동 잠금은 유지합니다.
6. 승인 후 빗나가거나 상대 방어·벽에 막혀도 게이지를 돌려주지 않습니다. 승인 후 사망·다운으로 남은 시전/공격이 종료돼도 환급하지 않습니다.
7. 같은 틱에 여러 R 요청이 와도 첫 유효 요청만 소비·시작하고, 나머지는 게이지 또는 시전 상태 검사에서 거절합니다.
8. 해당 틱의 피해 처리로 100%에 도달한 경우 다음 유효 입력부터 사용할 수 있습니다. 서버가 거절한 R 요청을 다음 틱에 자동 재실행하지 않습니다.

R 승인 시의 0% 소비와 이후 새 피해로 얻은 충전은 별도 사건입니다. 같은 틱 또는 시전 중에 새로 확정된 일반 공격·피격은 정상 충전할 수 있지만 자기 R 피해는 제외하고, 현재 궁극기 시전이 끝나기 전에는 다시 발동할 수 없습니다.

### 경기 수명

- 경기 시작 시 양쪽 0%. 연승으로 계속해도 새 경기에는 0%로 초기화합니다.
- 재접속은 같은 경기의 게이지·궁극기 진행 상태를 복원하며 0%로 리셋하지 않습니다.
- 경기 중 캐릭터 교체는 불가하고, 경기 사이 교체 후 새 경기에는 0%입니다.
- KO·무승부·시간 종료·기권·무효로 끝나면 100%여도 발동 불가입니다. 게이지가 경기 결과나 연승을 바꾸지 않습니다.

## 5. 서버·클라이언트 데이터 변경안

다음은 구현할 계약 제안이며 현재 메시지 타입은 그대로입니다. 변경 시 프로토콜·규칙 버전을 올리고 클라이언트와 서버를 함께 배포합니다.

```text
InputMessage (새 버전 제안)
  seq, x, y
  guardHeld: boolean
  skill?: S | D | F | Q | W | E | R

PlayerSnapshot (추가 제안)
  characterId
  guardState: inactive | starting | guarding
  guardDirection, guardActiveAt
  combatState: standing | downed | recovering
  downInstanceId, downUntil, recoveryUntil
  knockdownImmuneUntil, downFollowupUsed
  ultimateCharge: 0..10000
  cast / lastSeq / 일반 행동 쿨다운

DamageEvent (서버 내부)
  eventId, matchId, tick, sourceId, targetId, skillId
  sourceIsUltimate, actualHpDamage
```

- A는 `skill: A` 단발 요청으로 처리하지 않습니다. 키 누름·놓음을 `guardHeld`로 동기화하고 입력 만료 시 서버가 해제합니다.
- A만 누르거나 정지해 있어도 유지 입력을 250ms 안에 갱신합니다. 현재 30회/초 입력 상한을 지키며 포커스 상실 시 즉시 `guardHeld: false`를 보냅니다.
- 피해 이벤트와 실제 HP 감소는 서버가 만듭니다. 클라이언트에서 게이지·피해·궁극기 준비 여부를 올려 보내도 신뢰하지 않습니다.
- 일반 쿨다운과 A 유지 입력, R 게이지 소모를 스킬 정의의 발동 조건으로 구분합니다. R을 일반 `cooldownMs`만 검사하는 분기에 남겨 두지 않습니다.
- F에는 `targetStates: [downed]`, 일반 공격에는 `[standing]`를 정의합니다. 다운 유발 여부·시간·방어 가능 여부는 공격 데이터로 관리합니다. F는 대상과 다운 회차를 묶고 실제 명중 시 한 번의 추가 타격 사용을 원자적으로 처리합니다.
- 게이지·소비는 전투 틱에서 처리하고 매 프레임 DB를 쓰지 않습니다. F07은 같은 경기 복원, F06은 확정 결과·필요한 경기 요약만 저장합니다.
- 허용된 공격 사건은 한 번만 반영합니다. 재접속·메시지 재전송·결과 조회로 같은 이벤트의 충전을 반복하지 않습니다.

## 6. HUD·입력 표시

- 공통 키 설명과 튜토리얼을 새 배치로 갱신합니다. A는 유지 중 자세, S는 대시, D는 기본 공격, F는 다운 추가 공격으로 표시합니다.
- 양쪽 궁극기 게이지를 표시하는 초안입니다. 본인 R은 100%에서 준비 강조, 사용 직후 0%로 갱신합니다. 미충전 상태에서는 남은 초 대신 게이지를 보여 줍니다.
- 궁극기 이름·아이콘·설명은 선택 캐릭터에서 읽습니다. 100%라도 방어·시전·종료 상태이면 지금 발동할 수 없음을 구분합니다.
- 서버 응답 이전 클라이언트 예측으로 게이지를 올리거나 소모하지 않습니다. 표시는 마지막 확정 스냅샷을 기준으로 합니다.

### 다운·F 추가 수용 기준

| 시나리오                               | 기대 결과                                            |
| -------------------------------------- | ---------------------------------------------------- |
| 서 있는 상대·HP 0 상대에게 F 요청      | 발동·쿨다운 소비·피해·충전 없음                      |

F의 대상은 쓰러진 상대이며, 세부 충전 계수·방어 수치·다운 시간·기상·추가 공격 제한은 사용자 검수 후 확정합니다. 사용자가 승인한 UI 목업 공유 범위에 이 참고 명세를 포함합니다. 게임 판정·수치의 구현 완료를 뜻하지 않습니다.
