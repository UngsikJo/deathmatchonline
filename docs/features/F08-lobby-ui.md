# F08 — 로비·결과·휴식 UI

- 브랜치: `feature/lobby-ui`
- 우선순위: P0
- 상태: 기본 화면 구현, 실제 계정·정산·대기열 흐름 연결 미완료
- 기준: `bfe35d3`, [PRD](../PRD.md) 5·7절
- 선행 기능: F02, F04, F05, F06, F07, [기능 목록](README.md)

> 변경안 검수 대기: 주먹·검·활·마법의 4종 선택과 캐릭터별 스킬 HUD를 추가하는 안을 [캐릭터 기획안](../CHARACTERS.md)에 맞춰 검토합니다. 사용자의 UI/UX 브랜치 공유 요청에 따라 참고 명세로 반영하며 실제 게임 연결은 후속 작업입니다.

> 디자인 초기안 공유 승인: 무한의 계단을 참고한 [도트 아케이드 UI/UX·5화면 목업](../UI_UX_DESIGN.md)을 준비했습니다. 현재 연승·캐릭터·대전 시작 우선순위, 두꺼운 사각 버튼, 금색 강조, QWER/ASDF 바를 초기 기준으로 공유하고 추후 수정·구현합니다.

## 목표와 현재 상태

사용자가 지금 대기·전투·결과 저장 중 어느 단계인지 이해하고, 승리 후 계속하거나 연승을 보존하고 쉴 수 있게 합니다. 게임 메뉴를 일시정지로 오해하지 않게 합니다.

현재 `App.tsx`에 닉네임, 메모리 통계, 대전 찾기, HUD, 결과·기권 메뉴가 있습니다. 실제 DB 로딩·저장 오류·순위표 진입·승리 후 자동 매칭 옵션·음량 설정은 완성되지 않았습니다.

캐릭터 선택 화면도 아직 없습니다. 검수안에서는 로비에서 4종을 고르고 각 역할·8개 스킬을 살펴본 뒤 매칭합니다. 선택하지 않았으면 참가를 안내하고, 대기·전투·정산 중에는 교체를 막습니다. 상대 캐릭터는 양쪽 선택과 배정이 확정된 뒤 공개합니다.

## 화면과 동작

| 상태            | 필수 표시·행동                                                                       |
| --------------- | ------------------------------------------------------------------------------------ |
| 로비            | DB 프로필·현재/최고 연승·승패 수, 대전 찾기, 순위표, 설정                            |
| 계정/통계 로딩  | 로딩 상태, 미조회 기록을 실제 0승처럼 확정 표시하지 않음                             |
| 매칭            | 경과 시간, 취소, 재시도 가능 시각, 장기 대기 안내                                    |
| 준비·카운트다운 | 상대 표시, 에셋 로딩·준비 상태, 시작 전 입력 안내                                    |
| 전투            | 양쪽 체력, 서버 기준 제한 시간, 현재 연승, 방어·일반 쿨다운·궁극기 게이지, 연결 상태 |
| 저장 중         | F06 확정 대기, 다음 경기·반복 정산 요청 차단                                         |
| 확정 결과       | 결과 사유, 현재/최고 기록, 계속하기·쉬기                                             |
| 재접속 실패     | F07 결과 조회·로비 복귀, 의도하지 않은 새 매칭 금지                                  |

스킬 바는 위 `Q W E R`, 아래 `A S D F`로 배치합니다. 캐릭터 구분은 색상과 내 플레이어 표식을 함께 사용합니다. PC 웹이 범위이며 모바일 터치 컨트롤은 제외합니다.

스킬 이름·아이콘·설명·쿨다운은 선택한 캐릭터 정의에서 읽습니다. 주먹·검·활·마법이 한 개 스킬표를 공유하는 화면을 만들지 않습니다. 양쪽 캐릭터 유형과 서버가 확정한 선택 상태를 표시합니다.

## 휴식·기권·자동 매칭 규칙

1. 결과 화면에서 아무 입력이 없으면 다음 경기를 시작하지 않습니다. 쉬기·로그아웃은 확정된 연승을 바꾸지 않습니다.
2. 경기 메뉴는 전투를 멈추지 않습니다. 명확한 안내와 기권 확인을 제공하며 기권의 패배·연승 종료 효과를 보여 줍니다.
3. 승리 후 자동 매칭 옵션은 기본 해제입니다. 켜져 있어도 저장 확정 후 5초를 기다리고 취소할 수 있습니다. 패배·무승부·무효에는 자동 적용하지 않습니다.
4. 자동 매칭 대기 중 쉬기·옵션 해제·로그아웃·컴포넌트 종료 시 타이머를 해제합니다. 클릭과 타이머가 경쟁해도 참가 요청은 한 번만 발생합니다.
5. 명확한 서버 결과가 없으면 승리 배너·증가한 연승을 먼저 보여 주지 않습니다. 실패 시 같은 경기 저장 재시도와 로비 상태를 구분합니다.
6. 기본 음량·음소거는 로컬 설정에 저장합니다. 실제 오디오 재생·에셋은 F10이 제공하며 화면 클릭 후 브라우저 재생을 시작합니다.
7. 검수안은 경기 사이 캐릭터 변경을 허용하고 계정 연승을 보존합니다. 자동 매칭 카운트다운 중 선택을 바꾸려면 먼저 자동 매칭을 취소하고, 확정 선택으로 새 대기열 요청을 한 번만 보냅니다.

## 상태·데이터 계약

- 인증·프로필·통계·대기열·전투·연결·정산 상태를 분리해 하나의 `participating` 값에 모두 의존하지 않도록 정리합니다.
- 결과 표시의 기준은 F06 정산 영수증입니다. `Snapshot`의 전투 종료와 영구 저장 완료를 구분합니다.
- 취소·연속 클릭·비동기 응답 순서가 뒤바뀌어도 이전 경기 응답이 새 화면을 덮어쓰지 않도록 요청 세대와 경기 ID를 확인합니다.
- Canvas 입력 포커스와 폼 키 입력을 분리합니다. 키보드만으로 로비·설정·기권 확인을 사용할 수 있어야 합니다.

## 수용 기준

| 시나리오                            | 기대 결과                                        |
| ----------------------------------- | ------------------------------------------------ |
| 로비 통계 조회 실패                 | 명확한 오류·재시도, 0승 확정 표시 없음           |
| 승리 후 쉬기·재로그인               | 같은 연승 표시, 매칭 요청 없음                   |
| 저장 지연·실패                      | 다음 경기 시작 불가, 완료된 것처럼 표시하지 않음 |
| 자동 매칭 옵션 꺼짐                 | 결과 화면에서 자동 참가하지 않음                 |
| 자동 매칭 5초 중 취소와 타이머 경쟁 | 취소 상태 우선 확인, 참가 중복 없음              |
| 메뉴 열기                           | 전투 계속 안내, 상대·타이머·피해가 멈추지 않음   |
| 닉네임 입력·설정 조작               | 전투 스킬 오발동 없음, 포커스 이동 가능          |

추가 수용 기준: 선택 캐릭터에 맞는 스킬을 표시하고, 경기 중 교체 요청은 거절하며, 경기 사이 변경 시 검수된 연승 정책을 적용해야 합니다. 이름은 확정 전 분류용 호칭으로 표시합니다.

### 공통 조작·궁극기 HUD 변경안

- [공통 조작·궁극기 명세](../COMBAT_CONTROLS.md)를 기준으로 A 방어 유지·S 대시·D 기본 공격·F 쓰러진 상대 추가 공격·Q/W/E 기본 스킬 1/2/3·R 궁극기로 안내를 바꿉니다.
- A는 누름/해제와 현재 방어 자세를 표시하고, 다른 키처럼 남은 쿨다운만 보여 주지 않습니다. 포커스 상실·연결 종료 시 방어 유지가 풀려야 합니다.
- 양쪽 궁극기 게이지를 서버 값으로 표시합니다. 본인 R은 100%에서 준비 강조, 사용 승인 직후 0%, 미충전 상태에는 남은 초 대신 게이지를 보여 줍니다.
- 100%라도 방어·대시·시전·종료 상태이면 발동 제한을 구분합니다. 피해 애니메이션만 보고 게이지를 임의 증가시키지 않습니다.
- 서버에서 충전·소비가 확정된 뒤 화면을 갱신합니다. 재접속은 같은 값을 복원하고 새 경기에는 0%로 초기화합니다.
- 수용 기준: 새 키 배치와 안내가 일치하고 A 유지·해제·R 미충전·준비·소비 상태를 구분하며, 99%대 값을 반올림해 100% 준비로 표시하지 않습니다.

다운 관련 추가 UI 기준: 살아 있는 다운과 KO를 다른 자세·표식으로 표시합니다. F는 현재 다운 상대·사거리·일반 쿨다운을 기준으로 안내하고, 기상·면역·F 사용 완료를 구분합니다. 본인이 다운/기상 중이면 다른 행동·R이 잠긴 이유를 보여 주고 재접속 때 서버 상태로 복원합니다.
