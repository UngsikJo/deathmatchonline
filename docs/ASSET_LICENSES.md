# 에셋 출처

현재 외부 이미지·캐릭터·타일·아이콘·효과음 파일을 포함하지 않았습니다. 캐릭터와 경기장은 프로젝트 코드에서 임시 도형으로 그립니다.

현재 실행되는 게임 웹은 운영체제 기본 글꼴을 사용합니다. 별도의 UI 검수 목업은 아래의 Google Fonts 웹폰트를 불러옵니다. PRD의 Kenney·0x72·Game-icons 후보를 채택할 때 아래 표에 실제 다운로드한 파일 기준으로 기록합니다.

| 파일·팩 | 제작자 | 원본 URL | 라이선스 | 다운로드일 | 수정 | 게임 내 표기 |
| ------- | ------ | -------- | -------- | ---------- | ---- | ------------ |

사용한 오픈소스 패키지의 라이선스는 각 패키지에 포함된 LICENSE를 따릅니다. 공개 배포 시 패키지별 필요한 고지를 함께 확인합니다.

## UI 목업에서만 참조하는 글꼴

확인일은 2026-11-06입니다. 글꼴 바이너리를 저장소에 포함하거나 수정하지 않았고 Google Fonts를 통해 로드합니다. 차단·오프라인 환경에서는 시스템 대체 글꼴을 사용합니다. 실제 게임에 적용하거나 파일을 재배포할 때는 해당 저작권·라이선스 고지를 파일과 함께 포함합니다.

| 글꼴             | 제작자·저작권자                    | 라이선스 원문                                                                                | 목업 용도           |
| ---------------- | ---------------------------------- | -------------------------------------------------------------------------------------------- | ------------------- |
| Black Han Sans   | The Black Han Sans Project Authors | [SIL OFL 1.1](https://raw.githubusercontent.com/google/fonts/main/ofl/blackhansans/OFL.txt)  | 큰 한국어 제목·버튼 |
| IBM Plex Sans KR | IBM Corp.                          | [SIL OFL 1.1](https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexsanskr/OFL.txt) | 한국어 본문         |
| Press Start 2P   | The Press Start 2P Project Authors | [SIL OFL 1.1](https://raw.githubusercontent.com/google/fonts/main/ofl/pressstart2p/OFL.txt)  | 픽셀 기록 숫자      |

무한의 계단의 공식 스크린샷은 [디자인 조사](UI_UX_DESIGN.md)의 시각 참고 자료입니다. 해당 로고·캐릭터·이미지 파일을 저장소에 반입하지 않았습니다. 목업의 도트 캐릭터 4종과 경기장·무대는 직접 작성한 그리기 코드로 표현합니다.
