# F04 — 8개 스킬·전투 판정

- 브랜치: `feature/combat-skills`
- 우선순위: P0
- 상태: 전투 초안 구현, 예외·균형·표현 일치 검증 필요
- 기준: `bfe35d3`, [PRD](../PRD.md) 6·7절
- 선행 기능: F03, [기능 목록](README.md)

## 목표와 현재 상태

방향키와 8개 스킬만으로 공격·회피·방어가 가능한 공정한 1:1 전투를 제공합니다. 캐릭터 성능과 스킬은 양쪽이 동일합니다.

현재 `Simulation`에 시전·쿨다운·투사체·보호막·둔화·밀치기·승패 계산이 있습니다. 일부 규칙 테스트는 있으나 모든 경계 조합, 실제 플레이 균형과 벽에 가려진 예고 표시의 일치는 검증을 더 해야 합니다.

## 스킬 기준

아래는 현재 PRD 기본 수치입니다. 변경하면 공통 규칙·명세·테스트를 함께 갱신하고 규칙 버전을 올립니다.

| 키  | 효과                                     | 피해 | 시전 준비 | 쿨다운 |
| --- | ---------------------------------------- | ---- | --------- | ------ |
| A   | 전방 70px·90도 베기                      | 12   | 0.12초    | 0.7초  |
| S   | 직선 마력탄, 520px/s·사거리 480px        | 16   | 즉시      | 3초    |

## 공통 규칙·종료 조건

1. 체력 100, 마나 없음. 시전 시작부터 쿨다운 적용, 공통 발동 간격 0.25초, 시전 중 다른 스킬 사용 불가입니다.
2. 길게 누른 키 반복으로 연속 발동하지 않습니다. 동시 요청은 수신 순서, 같은 묶음은 A→S→D→F→Q→W→E→R 중 사용 가능한 첫 스킬만 선택합니다.
3. 같은 공격의 피해는 상대에게 1회만 적용합니다. 투사체는 이동 구간의 선분으로 검사하며 벽·최대 거리·명중 시 소멸합니다.
4. 보호막 초과 피해만 체력에 적용합니다. 둔화·밀치기는 보호막과 별개이며 둔화는 강도를 누적하지 않고 남은 시간만 갱신합니다.
5. 돌진·밀치기는 벽을 통과하지 않습니다. 캐릭터끼리 몸 충돌로 길을 막지 않습니다.
6. 한 틱의 피해를 모아 반영합니다. 같은 틱 양쪽 체력 0은 무승부입니다. 공격의 시전은 피격으로 취소하지 않습니다.
7. 120초가 지나면 남은 체력 비율로 판정하고 동률은 무승부입니다. 카운트다운 중 입력·투사체를 잠그고 새 경기에서는 체력·버프·쿨다운을 초기화합니다.
8. 서버의 `MatchResult`만 F06에 전달합니다. 영구 통계 갱신과 DB 저장은 이 기능에서 구현하지 않습니다.

## 데이터와 작업 항목

`SKILLS`, `RULES.version`, `Cast`, `Projectile`, `Effect`, `MatchResult`를 공통 계약으로 유지합니다. 클라이언트는 사용 의도만 전송하고 명중 대상·피해·승자를 지정하지 않습니다. F10은 서버의 시전·피격 이벤트에 맞춰 아트와 소리를 표시합니다.

- [ ] 모든 스킬의 거리·준비 시간·방향·시전 중 입력 경계 검사.
- [ ] 동일 입력 묶음의 스킬 우선순위와 중복 처리 규칙 명시·구현.
- [ ] 벽 뒤 투사체·넓은 공격 판정과 예고 그림 일치.
- [ ] 종료 틱에서 사망·시간 종료·기권 경쟁의 단일 결과 처리.
- [ ] 새 경기 초기화와 이전 투사체·효과의 제거.
- [ ] 실제 대전 10회 이상 수행 후 경기 길이·명중률·스킬 사용 편중 기록.
