# F05 — 공개 매칭·경기 준비

- 브랜치: `feature/matchmaking`
- 우선순위: P0
- 상태: 단순 방 참가 구현, 공개 대기열 정책 미완료
- 기준: `bfe35d3`, [PRD](../PRD.md) 5·8절
- 선행 기능: F01, F02, [기능 목록](README.md)

## 목표와 현재 상태

로그인한 사용자가 대전 찾기를 누르면 같은 지역·모드의 상대와 1:1 경기를 시작합니다. 경기 사이 휴식·매칭 취소는 연승에 영향을 주지 않습니다.

현재 `joinOrCreate('duel')`, 최대 2명, 렌더러 준비 신호·3초 카운트다운, 메모리 참가 잠금이 있습니다. 선착순 대기열, 반복 상대 회피, 배정·취소 경쟁, 영속 참가 잠금과 준비 단계 전체 시간 제한은 미완료입니다.

## 정책과 상태 전이

```text
idle → queued → preparing → countdown → active
        ↓           ↓           ↓
      cancel      timeout      leave
        └────────── 경기 미시작, 승패·연승 변화 없음
```

1. MVP는 단일 지역·공개 모드·대기 시간 우선입니다. 실력 점수 매칭·봇 투입·친선전은 P1입니다.
2. 같은 계정은 대기열 또는 경기에 한 번만 참여합니다. 자기 자신과 매칭하지 않습니다. 닉네임이 아니라 F01의 검증 사용자 ID로 판단합니다.
3. 배정 전 상대 이름·연승을 공개하지 않습니다. 매칭 취소와 배정이 경쟁하면 서버가 확정한 참가 상태를 반환합니다.
4. 양쪽 에셋 로딩·준비 완료까지 최대 15초를 부여합니다. 이후 3초 카운트다운 중 참가 상태가 유효한지 확인하고 F06의 경기 생성 완료 후 전투를 시작합니다.
5. 준비·카운트다운 이탈은 승패로 정산하지 않습니다. 10분 내 준비 취소·실패 3회 시 60초 대기 제한이라는 PRD 초안을 적용하고 서버 시간을 사용합니다.
6. 다른 상대가 있으면 직전 상대를 피합니다. 30초 이상 대기했고 대안이 없을 때 재매칭을 허용합니다. 이 조건이 대기열의 전체 정체를 만들지 않게 합니다.
7. 승자는 결과 확정 후 새 매칭에 참가합니다. 이전 경기 방·체력·버프를 이어받지 않습니다.
8. 배포 점검 시 새 참가를 거절하고 기존 활성 경기는 완료시킵니다. 종료 정산은 F06에 위임합니다.

## 추가 계약과 데이터 제안

- 대기열 참가·조회·취소를 위한 서버 API 또는 Colyseus 메시지를 추가합니다. 응답에는 `queueTicketId`, 상태, 서버 기준 참가 시각, 준비 기한·재시도 가능 시각을 포함합니다.
- 재시도된 참가 요청은 같은 유효 티켓을 반환합니다. 취소 요청도 여러 번 호출해도 같은 결과여야 합니다.
- `active_participations.user_id`의 유일 제약으로 중복 참가를 막고 `lease_expires_at`을 갱신합니다. 클라이언트가 직접 쓰지 못하게 합니다.
- 티켓·Colyseus 방 ID·F06의 DB 경기 UUID를 구분합니다. 티켓을 가진 계정만 배정된 좌석을 소비할 수 있습니다.
- F05는 대기·준비 잠금을 만들고, 활성 경기 전환은 F06과 함께 처리합니다. 장애 잠금 해제는 F07이 담당합니다.
- 오류는 미인증, 이미 참가 중, 준비 만료, 매칭 제한, 점검 중, 서버 부족으로 구분합니다.

| 조건                           | 기대 결과                                                  |
| ------------------------------ | ---------------------------------------------------------- |
| 사용자 두 명 참가              | 같은 공개 경기로 배정, 양쪽 준비 후에만 시작               |
| 같은 계정이 두 창에서 참가     | 유효 티켓 또는 경기 하나만 존재                            |

| 준비 미완료·카운트다운 이탈    | 경기 취소, 승패 미반영, 상대 잠금 정리                     |
| 준비 단계 반복 취소 기준 초과  | 서버 기한까지 재참가 제한                                  |
| 한 명만 대기                   | 실제 대기 안내·취소 가능, 가짜 상대·봇 승리 없음           |
| 결과 저장 실패 또는 점검 중    | 다음 경기 참가 거절, 기록 손실 없음                        |
