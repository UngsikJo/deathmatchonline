# F10 — 캐릭터·맵·효과음

- 브랜치: `feature/game-assets`
- 우선순위: P0, MVP 표현과 에셋 로딩 완성
- 상태: 코드 도형 캐릭터·맵만 구현, 외부 에셋 미반입
- 기준: `bfe35d3`, [PRD](../PRD.md) 4절과 [에셋 기록](../ASSET_LICENSES.md)
- 선행 기능: F03, F04, [기능 목록](README.md)

## 목표와 현재 상태

두 플레이어와 공격 방향·스킬 예고·피격을 즉시 구분할 수 있는 일관된 2D 표현을 만듭니다. 프로토타입의 임시 도형을 유지하는 안과 검증된 무료 에셋을 채택하는 안을 비교하고 선택을 기록합니다.

현재 Phaser Graphics로 캐릭터·격자·장애물을 그리고 오디오는 비활성화돼 있습니다. 타일 원본·방향별 스프라이트·효과음은 없으며 PRD의 에셋 후보도 다운로드·라이선스 파일 확인 전입니다.

## 포함 범위

- 전투 성능이 같은 캐릭터 1종과 내/상대 색·표식. 스킨 선택·능력치 차이 없음.
- 대기·이동·시전·피격·사망 표현. 8방향 조준과 애니메이션 프레임 방향은 별개로 처리합니다.
- 대칭 맵 1개, 시각·충돌·시작 위치 데이터의 일치.
- 8개 스킬의 범위 예고·투사체·명중·방어·둔화 표식.
- 버튼·매칭·카운트다운·시전·피격·승패 효과음과 기본 음량·음소거 연동.
- 로딩 진행·실패·재시도, 저작자·라이선스 고지.

## 디자인·동작 규칙

1. 첫 기본안은 16px 타일 기반 픽셀 스타일입니다. 채택 팩을 직접 확인해 프레임·타일 크기·사용 조건을 기록하며 서로 다른 화풍을 임의로 혼합하지 않습니다.
2. 애니메이션이 부족하면 조준 화살표·무기 궤적·간단한 이동 효과로 보완합니다. 부족한 프레임을 이미 제공되는 것처럼 문서화하지 않습니다.
3. 색상 외에 내 플레이어 표식·상대 표식을 함께 표시합니다. 체력·공격 예고는 배경 위에서 읽을 수 있어야 합니다.
4. 스프라이트 크기가 충돌 크기를 바꾸지 않습니다. 실제 판정 반지름 16과 스킬 범위는 F03·F04의 공통 데이터에서 가져옵니다.
5. Tiled를 채택하면 시각·충돌·spawn 데이터를 공통 JSON으로 내보냅니다. 서버와 클라이언트가 같은 버전·해시의 데이터를 로딩해야 합니다.
6. 공격 예고의 벽 차단·방향·지속 시간은 F04 판정과 일치하게 만듭니다. 눈속임으로 서버 판정을 덮어쓰지 않습니다.
7. 브라우저 오디오는 사용자 조작 이후 시작합니다. 음소거 상태와 음량을 존중하고 재접속·스냅샷 반복 수신으로 같은 소리를 중복 재생하지 않습니다.
8. 모든 필수 에셋 로딩 완료 후에만 F05의 준비 신호를 보냅니다. 실패하면 준비 완료를 보내지 않고 오류·취소를 제공합니다.

## 에셋·이벤트 계약

- manifest에 에셋 ID, 파일 경로, 버전·해시, 프레임·타일 규격을 기록합니다. 서버 판정 데이터와 화면 파일을 구분합니다.
- 필요한 시전·피격 이벤트는 서버 이벤트 ID와 시뮬레이션 시각을 사용해 한 번만 표현합니다. 소리 누락을 보완하기 위해 피해를 재계산하지 않습니다.
- CC0 후보는 Kenney Tiny Dungeon·0x72 DungeonTileset II이며 실제 채택 전 원본 라이선스 파일을 확인합니다. 아이콘·음향은 개별 파일별 이용 조건을 기록합니다.
- `docs/ASSET_LICENSES.md`에 제작자·원본 URL·라이선스·다운로드일·수정·표시 위치를 추가하고 필요한 크레딧을 게임에 제공합니다.
- 유료 에셋·새 이미지 생성·외주 발주는 별도 사용자 선택이며 이번 명세 작성으로 구매하거나 제작하지 않습니다.
