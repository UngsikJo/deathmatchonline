# 시작 캐릭터 4종 설정·기술 기획안

- 작성·수정일: 2026-11-06, 한국 시간
- 상태: **세부 기획 초안 — UI 목업의 참고 명세로 `feature/lobby-ui`에 공유, 게임 구현 전**
- 사용자 지정: 주먹·검·화살·마법의 4종, 정식 이름 미정
- 사용자 지정 조작: A 웅크려 막기, S 대시, D 기본 공격, F 쓰러진 상대 공격, Q/W/E 기본 스킬 1/2/3, R 궁극기
- 사용자 지정 궁극기: 공격 성공·피격 피해로 게이지 충전, 100%에서 활성화
- 검수할 세부안: 인물·외형, 개별 기술·수치, 다운 유발·기상·추가 공격 제한, 충전 계수와 선택 정책
- 관련 문서: [조작·게이지 상세 명세](COMBAT_CONTROLS.md), [PRD](PRD.md), [README](../README.md)

> 주먹형·검형·활형·마법형은 분류용 호칭입니다. 정식 이름이 아닙니다. 아래는 사용자가 지정한 종류와 조작에 맞춘 세부 제안이며, 검수 후 구현합니다. 현재 코드는 이전의 단일 임시 스킬 구성을 사용하고 있습니다.

## 1. 캐릭터 구성

4종은 같은 역할의 키를 사용하면서 기본 공격·다운 추가 공격·Q/W/E·궁극기를 각자 다르게 구성합니다. A는 공통 웅크려 막기이고 S는 공통 대시 역할입니다. **4종 × 8개 입력 항목 = 32개 항목**이며, 공통 행동까지 모두 서로 다른 고유 스킬이라고 부르지 않습니다.

| 분류용 호칭 | 내부 ID 초안 | 전투 역할                | 강점                            | 약점                             |
| ----------- | ------------ | ------------------------ | ------------------------------- | -------------------------------- |
| 주먹형      | `brawler`    | 접근 후 근접 압박        | 빠른 타격·전진 공격·근거리 광역 | 짧은 사거리, 진입 실패 시 빈틈   |
| 검형        | `sword`      | 간격 조절·받아치기       | 긴 찌르기·타이밍 방어·짧은 검기 | 공격 방향·받아치기 타이밍에 의존 |
| 활형        | `archer`     | 원거리 견제·거리 유지    | 빠른 화살·둔화·밀침             | 근접 압박과 엄폐물에 취약        |
| 마법형      | `mage`       | 범위 제어·공격 위치 설계 | 지면 폭발·둔화 지역·보호막      | 긴 예고·짧은 대시·대응 자원 제한 |

같은 캐릭터는 같은 기본 조건을 사용합니다. 레벨·유료 장비·연승에 따른 전투 능력 보너스는 없습니다.

## 2. 공통 수치·조작·궁극기

| 항목              | 공통 초안                                                            |
| ----------------- | -------------------------------------------------------------------- |
| 체력·이동·몸 크기 | HP 100, 180px/s, 반지름 16                                           |
| 일반 자원         | 별도 마나·기력·화살 개수 없음                                        |
| 조준              | 마지막 유효 이동 방향, 대각선 포함 8방향                             |
| A                 | 누르고 유지하는 웅크려 막기, 첫 준비 0.08초, 정면 직접 피해 50% 감소 |
| S                 | 조준 방향 대시, 무적·벽 통과 없음                                    |
| D                 | 캐릭터별 기본 공격                                                   |
| F                 | 쓰러진 상대에게만 사용하는 추가 공격, 사용자 확인 완료               |
| Q/W/E             | 캐릭터별 기본 스킬 1/2/3                                             |
| R                 | 캐릭터별 궁극기, 100%에서 R 입력 시 전부 소비                        |
| 충전 계수         | 일반 실제 HP 피해 1당 공격자 +2%, 피격자 +1%라는 검수안              |
| R 시간 쿨다운     | 없음, 재충전 필요. 자기 R 피해로 자기 게이지 충전 없음               |
| 경기 수명         | 새 경기 0%, 같은 경기 재접속은 기존 게이지 복원                      |
| 경기              | 120초, HP 0 또는 종료 시 남은 체력 비율로 판정                       |

A 유지 중에는 움직이거나 다른 행동을 사용할 수 없고 방어 방향도 고정합니다. A를 놓거나 포커스·연결을 잃으면 해제합니다. S/D/F/Q/W/E는 일반 쿨다운, R은 게이지를 검사합니다. A를 제외한 행동은 키를 누른 순간 1회 요청합니다.

일반 행동의 공통 발동 간격은 0.25초입니다. 시전·대시·연속 공격을 겹치지 않습니다. R 준비·연타 중에는 이동 불가이고, 일반 준비 동작은 이동 가능한 기본안입니다. 방향은 시전 시작 시 고정합니다.

F는 서버가 확인한 살아 있는 다운 상대와 현재 다운 회차에만 명중합니다. 다운되지 않은 상대나 KO 상대에게는 사용할 수 없습니다. 초기 세부안은 다운 1.0초, F 유효 적중 1회 뒤 0.3초 기상, 완전히 일어난 뒤 1.5초 다운 면역입니다. 자세한 상태 전이·판정·검증은 공통 명세를 따릅니다. 미표기 근접 부채꼴은 90도를 기본안으로 합니다.

아래 거리·피해·준비 시간·일반 쿨다운과 기술 이름은 검수용 수치입니다. 실제 HP 피해·방어·보호막·오버킬·궁극기 소비는 [공통 상세 명세](COMBAT_CONTROLS.md)의 순서를 사용합니다. 공격당 중복 판정과 같은 피해 사건의 중복 충전을 금지합니다.

## 3. 주먹형 — 붙어서 밀어붙이는 전투

### 인물 설정 초안

무기보다 몸의 감각과 반복 훈련을 믿는 근접 전투가입니다. 한 번의 큰 기술보다 상대 반응을 읽고 거리를 좁히는 데 집중하며, 짧고 단단한 동작으로 싸웁니다. 이름·성별·나이·구체적 소속은 정하지 않습니다.

- 실루엣: 건틀릿 또는 손 붕대, 짧은 소매, 전방으로 기울어진 자세.
- 표현: 짧은 타격 궤적, 충격 원, 빠른 발 구르기. 공격보다 몸 자체가 잘 읽히게 만듭니다.
- 전투 흐름: 접근 → 잽·정권으로 반응 확인 → 다리 걸기·파운딩으로 연계 → 방어·대시로 재정비.
- 상대 대응: 진입 기술을 피하고 준비 중인 연타의 범위에서 벗어나 거리를 다시 벌릴 수 있습니다.

## 4. 검형 — 간격과 받아치기로 싸우는 전투

### 인물 설정 초안

간결한 검술로 상대의 빈틈을 기다리는 전투가입니다. 상대가 먼저 실수하도록 간격을 유지하고, 무리한 접근에는 짧은 받아치기로 대응합니다. 특정 국가·기사단·복수 서사는 정하지 않습니다.

- 실루엣: 한손 또는 양손으로 드는 중간 길이 검, 가벼운 보호구, 안정적인 옆 자세.
- 표현: 칼날 방향과 실제 공격 범위가 일치하는 선명한 검격. 과도하게 긴 검광으로 사거리를 오해하게 하지 않습니다.
- 전투 흐름: 칼끝 거리 유지 → 찌르기·검기로 견제 → 상대의 진입을 받아침 → 검격·일섬으로 마무리.
- 상대 대응: 검 끝 바깥에서 견제하거나 방어 타이밍을 비운 뒤 접근할 수 있습니다.

## 5. 활형 — 거리를 유지하며 맞히는 전투

### 인물 설정 초안

발걸음과 조준으로 전장을 읽는 원거리 전투가입니다. 빠르게 움직이며 상대의 진입 경로를 끊고, 충분한 거리를 만든 뒤 정교한 한 발을 노립니다. 종족·성별·소속은 정하지 않습니다.

- 실루엣: 활과 작은 화살통, 가벼운 장비, 긴 이동 동작. 화살통은 장식이며 탄약 제한은 없습니다.
- 표현: 화살의 진행 방향과 꼬리 궤적, 활을 당기는 준비 동작. 작은 투사체도 배경에서 읽히게 만듭니다.
- 전투 흐름: 일반 화살 견제 → 대시·둔화로 간격 확보 → 산개·넘어뜨림으로 진입 방해 → 결정 화살.
- 상대 대응: 엄폐물로 직선을 끊고, 후퇴 기술이 빠진 순간 거리를 좁힐 수 있습니다.

## 6. 마법형 — 예고한 영역을 지배하는 전투

### 인물 설정 초안

집중과 계산으로 상대의 이동을 유도하는 전투가입니다. 강한 마법을 곧바로 맞히기보다 상대가 피할 위치를 읽고 다음 범위를 설계합니다. 원소·마법 학파·상세 세계관은 추후 결정합니다.

- 실루엣: 짧은 지팡이 또는 촉매, 구별되는 상체 장식, 간결한 로브. 몸의 실제 위치가 가려지지 않게 만듭니다.
- 표현: 준비 상태가 읽히는 마법진·범위 테두리, 눈에 띄는 발사 순간. 내/상대의 시각 구분은 공통 표식을 유지합니다.
- 전투 흐름: 마력탄 견제 → 둔화 지역으로 이동 유도 → 지면 폭발 → 집중 광선. 근접 압박에는 보호막·대시로 대응하고 둔화 지역으로 거리를 다시 만듭니다.
- 상대 대응: 긴 준비 동작을 보고 범위를 벗어나거나 이동·방어 자원이 빠진 시점에 접근할 수 있습니다.

### 공통 행동과 캐릭터별 기술 8개

| 키  | 동작·가칭   | 효과·거리                                                                  | 피해 | 준비   | 재사용 조건      |
| --- | ----------- | -------------------------------------------------------------------------- | ---- | ------ | ---------------- |
| A   | 웅크려 막기 | 마력으로 몸을 감싸는 공통 A 자세, 별도 보호막 HP 없음                      | 0    | 0.08초 | 유지 입력        |
| S   | 마력 대시   | 조준 방향 최대 90px를 0.16초 동안 이동, 점멸 아님                          | 0    | 즉시   | 6초              |
| D   | 마력탄      | 속도 420px/s·사거리 260px의 투사체 1개                                     | 10   | 0.1초  | 1초              |
| F   | 다운 파동   | 살아 있는 다운 상대만, 전방 70px·120도 추가 타격 1회                       | 10   | 0.2초  | 2.5초            |
| Q   | 폭발진      | 전방 최대 160px·반경 70px 지면 폭발, 유효 HP 피해 시 1초 다운, A 감소 불가 | 20   | 0.6초  | 10초             |

| E   | 둔화 지대   | 전방 최대 120px, 반경 55px 지역 2초 유지, 내부 30% 둔화                    | 0    | 0.35초 | 10초             |
| R   | 집중 광선   | 전방 길이 320px·폭 48px 예고 후 직선 마법 1회                              | 30   | 0.9초  | 게이지 100% 소비 |

A의 마력 표현은 공통 50% 방어일 뿐 W 보호막 수치를 자동으로 주지 않습니다. Q 중심은 시전 시작에 정하고 따라가지 않습니다. E는 피해가 없어 그 자체로 게이지를 충전하지 않으며, 지역을 벗어나면 둔화를 최대 0.3초만 남깁니다. F는 다운 상대만 때리며 추가 다운·밀치기를 만들지 않습니다. Q는 유효 HP 피해가 나면 다운을 유발하지만 대상이 다운 면역이면 피해만 적용합니다. R은 투사체가 아닌 직접 직선 마법으로 정면 A 감소를 받습니다.

### 다운 연계의 공통 규칙

- 다운은 HP가 남아 있는 상태입니다. HP 0은 KO로 경기 종료이며 다운 타격 대상이 아닙니다.
- 주먹형 E·검형 Q·활형 E·마법형 Q의 유효 타격이 초기 다운 원인입니다. A로 유효하게 방어했거나 보호막 때문에 HP 피해가 0이면 다운하지 않습니다. 마법형 Q는 지면 공격이므로 A 감소 조건을 받지 않습니다.
- 각 F는 다운 회차당 한 번만 유효 적중하고 HP가 남으면 즉시 기상 단계로 전환합니다. 다운·기상 시간을 연장하지 않으며 추가 다운·밀치기·둔화를 주지 않습니다.
- 기본안에서 일반 공격은 서 있는 상대, F는 다운 상대만 판정합니다. 다운 중 A/S/D/F/Q/W/E/R은 발동하지 못하고, 기상 중에는 조작·새 피격을 잠급니다.
- 기상 완료 후 1.5초 동안 다시 다운되는 것만 막고 일반 피해·조작은 정상입니다. 다운·기상·F 사용 여부는 서버와 같은 경기 재접속에서 보존합니다.
- F 실제 HP 피해도 일반 공격과 같은 충전 계수안을 적용합니다. 다운 유발 자체나 보호막에 모두 흡수된 F로는 게이지를 얻지 않습니다.

## 7. 방어와 궁극기의 연결

공통 A는 정면 직접 피해 감소입니다. 검형 W는 정면 타격 1회 완전 무효, 마법형 W는 피해 합계 흡수로 구분합니다. 처리 순서는 무효 → 피해 감소 → 올림 → 보호막 → HP입니다. 둔화·밀치기는 단순 피해 감소·흡수만으로 없어지지 않습니다.

궁극기는 서버가 확정한 실제 HP 피해로 충전합니다. 초기 계수안은 일반 공격자 2%/피격자 1%이며, 허공 공격·보호막 흡수·상태 효과만으로 충전하지 않습니다. R은 100%에서 키 입력을 받아 게이지 전부를 소비하며 자기 궁극기 피해로 다시 충전하지 않습니다. 명중에 실패해도 소비를 환급하지 않습니다.

새 경기에는 0%, 같은 경기 재접속은 기존 게이지를 복원합니다. 자세한 숫자 예시·오버킬·중복 피해·궁극기 검증은 [조작·게이지 명세](COMBAT_CONTROLS.md)를 기준으로 합니다.

## 8. 캐릭터 선택과 연승 정책 초안

1. 처음부터 4종을 모두 선택하는 안입니다. 잠금 해제·유료 구매·능력치 성장은 없습니다.
2. 로비에서 선택 후 대기열에 들어가고 대기·준비·전투·정산 중에는 바꾸지 못합니다. 상대 유형은 양쪽 선택·배정 확정 뒤 공개합니다.
3. 같은 캐릭터 대전을 허용합니다. 한 명의 선택이 다른 사람의 선택을 막지 않습니다.
4. 계정 연승은 경기 사이 캐릭터를 바꿔도 보존하는 안입니다. 주먹형 2승 뒤 검형 1승이면 계정 3연승입니다.
5. 같은 경기 재접속은 캐릭터·기술·HP·쿨다운·게이지·현재 궁극기 시전을 복원합니다.
6. 새 경기는 선택 캐릭터의 HP·일반 쿨다운·상태 효과와 게이지 0%로 시작합니다. 이전 경기 궁극기를 들고 오지 않습니다.
7. 순위표는 계정 최고 연승 기준입니다. 캐릭터별 순위는 후속 범위로 둡니다.

이 선택·연승 정책은 검수 후 확정합니다. 궁극기 게이지는 연승과 별개인 경기 안의 자원입니다.

## 9. 구현 데이터 제안

현재 전역 SKILLS와 S/W에 한정된 투사체, R 고정 쿨다운을 변경해야 합니다. 아래는 승인 후 구현할 구조입니다.

```text
CharacterDefinition
  id: brawler | sword | archer | mage
  displayName: 정식 이름 미정, 초기 화면에는 분류용 호칭
  baseStats: maxHp, moveSpeed, bodyRadius
  actions: A / S / D / F / Q / W / E / R

ActionDefinition
  id: 캐릭터 ID + 슬롯, 예: archer.D
  activation: hold | cooldown | ultimate
  castTime / cooldown / damage / range / shape / targetStates
  knockdown / knockdownDuration / requiresHpDamage
  projectile / movement / defense / status / sequence
  animation / effect / sound 참조
```

- A는 유지 입력·방어 상태, S/D/F/Q/W/E는 일반 행동, R은 궁극기 게이지 조건으로 분리합니다. 단일 쿨다운 테이블만으로 A·R을 처리하지 않습니다.
- 서버는 고정된 characterId로 요청 슬롯의 행동을 찾습니다. 사용자가 다른 캐릭터의 기술·피해·게이지를 제출하지 못하게 합니다.
- 투사체·피해·효과에 ownerId·characterId·skillId·궁극기 여부를 연결합니다. 활형 D/F/Q/W/E/R, 검형 E, 마법형 D처럼 여러 슬롯의 투사체를 허용합니다.
- 경기 기록에 캐릭터 ID·규칙 버전을 남깁니다. 액티브 게이지는 서버의 경기 상태이며 매 틱 DB에 저장하지 않습니다.
- 공통 충돌·변위·피해·상태 계산을 조합해 캐릭터마다 전투 엔진 전체를 복제하지 않습니다.

## 11. 검증 기준

- 4종 모두 A/S/D/F가 방어·대시·기본·다운 추가 공격, Q/W/E가 기본 스킬 1/2/3, R이 궁극기로 연결돼야 합니다.
- 32개 항목에 누락·중복·옛 키 역할이 없어야 합니다. A는 유지 입력으로 분리하고 R에는 예전 고정 시간 쿨다운이 없어야 합니다.
- 게이지 충전·100% 미만 거절·유효 사용 전부 소비·중복 사용·피해 사건 재처리를 검증합니다.
- 방어·보호막·오버킬·다단 피해와 궁극기 자체 피해의 충전 차이를 검증합니다.
- 같은 경기 재접속의 게이지 보존, 새 경기의 0%, 경기 중 캐릭터 변경 거절을 확인합니다.
- 서 있는 대상·KO 대상 F 거절, 한 다운 회차 F 1회, 기상과 동시 명중·과거 회차 투사체·다운 면역을 검증합니다.
- 미러전 4종·서로 다른 조합 6개와 좌우 시작 위치를 바꾼 16개 배치를 확인합니다.
- 경기 길이·실제 피해·방어 유지 시간·궁극기 첫 충전 시점·사용 횟수·명중률을 기록해 밸런스를 조정합니다. 현재 수치는 플레이 검증 완료값이 아닙니다.

## 12. 사용자 검수 항목

- [ ] F 대상은 쓰러진 상대라는 사용자 지정을 적용하고, 다운 1초·F 1회 뒤 기상·기상 0.3초·이후 다운 면역 1.5초라는 세부안이 적절한가?
- [ ] A 유지 중 이동·공격 불가, 정면 피해 50% 감소라는 세부안이 맞는가?

- [ ] 자기 R 피해는 재충전하지 않고, 피격자는 R 피해로도 충전하는 안이 괜찮은가?
- [ ] 새 경기마다 게이지 0%, 100%에서 수동 발동·전부 소비하는 안이 맞는가?
