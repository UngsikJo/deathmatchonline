# F03 — 방향키 이동·방향 조준

- 브랜치: `feature/movement`
- 우선순위: P0
- 상태: 기본 이동 구현, 조작·보정 품질 확장 명세
- 기준: `bfe35d3`, [PRD](../PRD.md) 6·10절
- 선행 기능 없음, [기능 목록](README.md)

## 목표와 현재 상태

방향키로 즉시 움직이며 멈춘 후에도 마지막 이동 방향으로 스킬을 조준합니다. 대각선 속도·포커스 전환·서버 보정이 승부에 영향을 주는 입력 오류를 만들지 않아야 합니다.

현재 방향키 수집, 정규화, 벽 충돌, 서버 입력 순번 검사, 250ms 입력 만료, 로컬 이동 후 연속 보정이 있습니다. 처리되지 않은 입력 이력을 재실행하는 완전한 예측은 없고 실제 두 PC 조작 품질은 미검증입니다.

## 입력·이동 규칙

| 항목           | 요구 동작                                                |
| -------------- | -------------------------------------------------------- |
| 이동           | ↑↓←→, 동시에 누른 반대 방향은 해당 축 0                  |
| 대각선         | 벡터 정규화, 직선과 같은 총 이동 속도                    |
| 조준           | 마지막 유효 이동 방향 유지, 최초에는 상대 시작 위치 방향 |
| 기본 수치      | 속도 180px/s, 반지름 16, 경기장 960×640                  |
| 입력 유효 상태 | 전투 중, 본인 경기장에 포커스가 있을 때                  |
| 포커스 상실    | 누른 키 해제·정지 입력 전송, 서버는 250ms 만료 적용      |
| 벽             | 몸 반지름을 포함해 차단, 큰 이동도 벽을 관통하지 않음    |
| 방향+스킬      | 같은 입력 묶음의 이동 방향을 스킬 시전 방향으로 사용     |

방향별 그림과 서버의 조준 방향은 분리합니다. 마우스 조준·모바일·키 재지정은 이번 범위에서 제외합니다. 돌진 이동의 발동·무적 여부는 F04가 결정하고, 충돌·변위 계산은 공통 이동 모듈을 사용합니다.

## 메시지와 보정 계약

- 기존 `InputMessage`: `{ seq, x, y, skill? }`. 유한한 축 값, 범위 -1~1, 안전한 정수 순번만 허용합니다.
- 서버는 계정·방에 연결된 플레이어만 갱신하고 이전 순번을 무시합니다. 클라이언트가 좌표·속도를 직접 정하지 못하게 합니다.
- 스냅샷의 `lastSeq`까지 처리된 입력은 제거하고 남은 입력으로 예측을 재구성하는 방식을 도입·비교합니다. 브라우저 FPS와 무관한 고정 주기 입력 이력을 사용합니다.
- 재접속·새 경기에서는 이전 경기 입력과 보정 버퍼를 폐기합니다. 입력 순번 복원은 F07과 맞춥니다.
- 상대 이동은 보간하며 순간이동 수준의 오차만 명확한 기준으로 즉시 보정합니다. 임계값은 측정 결과와 함께 기록합니다.

## 작업 항목

- [ ] 브라우저 키 반복·IME·보조키·텍스트 입력 포커스 충돌을 정리.
- [ ] 고정 주기 입력 이력과 서버 확인 순번 기반 재실행 구현·검증.
- [ ] 느린 프레임·지연·지터에서 보간과 보정 강도 측정.
- [ ] 재접속·경기 전환·취소 후 입력 버퍼와 키 상태 초기화.
- [ ] 실제 키보드에서 방향키 2개+스킬 조합 및 포커스 상실 확인.

## 수용 기준

| 조건                                  | 기대 결과                                             |
| ------------------------------------- | ----------------------------------------------------- |
| 같은 시간 직선·대각선 이동            | 이동 거리 동일, 벽이 없을 때 속도 일치                |
| 양쪽 반대 방향 동시 입력              | 해당 축 이동 없음, 이전 조준은 불필요하게 바뀌지 않음 |
| 입력을 누른 채 창 전환·키 이벤트 누락 | 최대 입력 만료 시간 후 서버 이동 정지                 |
| 채팅이 아닌 일반 텍스트 입력창 편집   | 게임 스킬이나 이동이 발생하지 않음                    |
| 조작 순번·좌표·속도 조작              | 잘못된 메시지 거절, 서버 상태 유지                    |
| 30fps와 60fps 클라이언트 비교         | 같은 입력 시간의 서버 이동 거리 동일                  |
| 서버 보정·재접속·새 경기              | 이전 입력이 중복 적용되거나 캐릭터가 계속 달리지 않음 |

자동 검증은 거리·입력 만료·충돌·순번을 확인합니다. 실제 두 PC 및 지연 실험은 입력-화면 반응과 보정 오차를 기록합니다. 테스트를 수행하기 전 완료로 표시하지 않습니다.
