# F01 — 회원가입·로그인·계정 관리

- 브랜치: `feature/auth`
- 우선순위: P0
- 상태: 기능 명세 초안, 구현·실서비스 검증 미완료
- 기준: `bfe35d3`의 인증 프로토타입과 [PRD](../PRD.md) 9절
- 공통 진행 방법: [기능 목록](README.md)

## 목표와 사용자 흐름

이메일로 가입하고 인증을 마친 사용자가 같은 계정으로 재로그인하여 대전과 기록을 이어 갑니다. 가입 → 메일 인증 → 로그인 → 대전 가능 상태로 전환합니다. 비밀번호를 잊었으면 재설정 메일 → 새 비밀번호 저장 → 로그인 흐름을 제공합니다.

## 현재 상태

`AuthPanel.tsx`에 가입·로그인·재설정·비밀번호 갱신 UI가 있고, 서버는 Supabase `getUser(token)`과 이메일 인증 여부를 확인합니다. 실제 SMTP·복귀 URL 테스트, 세션 만료 처리의 전체 흐름, 계정 삭제 기능은 완료되지 않았습니다. 게스트 모드는 개발 편의 기능입니다.

## 범위와 규칙

1. 이메일·비밀번호 가입, 인증 메일 안내·재발송, 로그인·로그아웃, 비밀번호 재설정·갱신을 제공합니다.
2. 공개 대전은 유효한 access token과 인증 완료 이메일이 있는 계정만 허용합니다. 개발 게스트는 설정으로 명시적으로 분리합니다.
3. 제출 중 중복 요청을 막고, 만료·잘못된 인증 링크·발송 제한·네트워크 오류를 서로 구분해 안내합니다. 비밀번호 원문을 저장하거나 로그에 남기지 않습니다.
4. 다음 매칭 전 세션을 갱신합니다. 이미 시작한 경기는 토큰 만료만으로 무효 처리하지 않고 서버 참가 신원을 유지합니다. 재접속 검증은 F07과 연결합니다.
5. 전투·정산 중 로그아웃·탈퇴는 즉시 실행하지 않습니다. 먼저 기권 또는 결과 확정을 거친 뒤 처리합니다.
6. 탈퇴는 사용자가 내용을 확인하고 재인증한 뒤 서버 전용 경로에서 수행합니다. 진행 경기·참가 잠금·정산 유무를 다시 확인합니다. 본인 통계·프로필은 삭제하고 타인 경기 기록은 사용자 식별 정보를 제거하는 기본안으로 F06과 연결합니다.
7. 소셜 로그인·다중 인증은 P1입니다. 이 브랜치에서 전적 정산을 작성하지 않습니다.

## 인증 계약과 데이터

- 현재 참가 옵션의 `token`은 Supabase access token입니다. 서버는 제출한 사용자 ID를 신원 근거로 사용하지 않습니다.
- 서버가 검증한 `userId`, 이메일 인증 상태, 세션 유효 여부를 후속 기능에 제공합니다. 다른 사용자에게 이메일을 공개하지 않습니다.
- 기존 `signUp`, `signInWithPassword`, `resetPasswordForEmail`, `updateUser` 흐름에 세션 복원·링크 복귀를 연결합니다. 탈퇴는 본인 재인증을 요구하는 서버 API를 추가하는 제안입니다.
- UI 상태는 `idle`, `submitting`, `verification-required`, `authenticated`, `recovery`, `error`로 분리합니다. 인증 공급자의 내부 오류를 토큰과 함께 노출하지 않습니다.
- 회원 프로필 생성과 닉네임은 F02, 기록의 삭제·익명화 정합성은 F06이 소유합니다.

## 수용 기준

| 조건                             | 기대 결과                                                  |
| -------------------------------- | ---------------------------------------------------------- |
| 가입 후 인증 전 대전 요청        | 참가 거절, 메일 인증 안내                                  |
| 인증 메일 확인 후 로그인         | 정상 참가 가능, 같은 사용자 ID 유지                        |

| 링크가 만료됐거나 이미 처리됨    | 재발송 경로 제공, 기존 세션 오염 없음                      |
| 진행 경기 중 로그아웃·탈퇴       | 결과 처리 전 계정이 삭제되거나 연승이 보존되는 우회가 없음 |
| 탈퇴 재인증 완료, 활성 경기 없음 | 본인 데이터 삭제·익명화, 타인 통계 유지                    |
