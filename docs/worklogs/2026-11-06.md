## 1. 작업 목표

방향키 이동과 `A S D F Q W E R` 스킬을 사용하는 웹 기반 2D 1:1 연승 데스매치의 개발 출발점을 준비했습니다. 1인 개발자가 실행·검증하고 기능별로 이어 작업할 수 있도록 코드 구조, 기획서, 명세서와 Git 브랜치를 정리했습니다.

## 2. 완료한 작업

### 제품 요구사항과 기술 방향

- [PRD](../PRD.md)에 게임 목표, 조작, 전투·연승·휴식·기권·재접속 정책, MVP 범위와 준비 사항을 정리했습니다.

- 개발용 메모리 연승·승패 기록, 중복 참가·중복 정산 방지, 기본 재접속을 추가했습니다.

## 5. 확인된 제한과 보류 사항

- 현재 전적은 프로세스 메모리에만 저장되며 서버를 재시작하면 초기화됩니다. Supabase 인증 연결만으로 영구 저장이 되지는 않습니다.
- 실제 Supabase 가입·인증 메일·비밀번호 재설정 메일과 DB migration·RLS의 실계정 검증은 아직 수행하지 않았습니다.
- 브라우저 자동화 연결을 사용할 수 없어 화면의 시각 검증은 수행하지 못했습니다. 실제 두 PC 플레이 테스트가 필요합니다.
- Git HTTPS 인증에는 `workflow` 권한이 없고, 연결된 GitHub 앱도 워크플로 파일 생성 권한이 없어 자동 CI를 활성화하지 못했습니다. 템플릿과 수동 활성화 안내를 보관했습니다.
- 공개 서비스 배포·외부 계정 생성·유료 서비스 계약은 하지 않았습니다. production 시작 제한을 유지했습니다.
- 최종 캐릭터·맵·음향은 미반입이며 Phaser 엔진 청크 용량 경고도 남아 있습니다.
