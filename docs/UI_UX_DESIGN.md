## 2. 제안 방향

**큰 연승 숫자 + 도트 캐릭터 무대 + 한눈에 보이는 대전 시작 버튼**을 중심으로 구성합니다. 어두운 석재·타일 배경, 크림색 글자, 금색 버튼으로 아케이드 분위기를 만듭니다. 두꺼운 테두리와 3~4px 눌림 깊이를 사용하며 둥근 카드·유리 효과·복잡한 장식은 최소화합니다.

무한의 계단에서 참고하는 부분은 도트 표현과 화면의 우선순위입니다. 이 게임에는 웹 키보드 1:1 전투에 맞는 가로형 탑다운 경기장, QWER/ASDF 기술 바, 양쪽 체력과 궁극기 게이지를 설계합니다. 이름은 `Deathmatch Online`을 유지하고 캐릭터 호칭은 주먹형·검형·활형·마법형으로 표시합니다.

## 3. 목업 화면과 연결

편집 원본은 `docs/design/deathmatch-arcade-mockup.html`입니다. 대화에 표시되는 검수 화면에서 상단의 로비·캐릭터·전투·결과·로그인 탭으로 전환합니다. **상단 화면 탭과 하단의 예시 상태 선택은 검수 도구이며 실제 게임 메뉴가 아닙니다.** 화면 수치·접속·전적·매칭은 모두 예시입니다.

| 화면            | 우선순위와 표시                                           | 확인할 동작                                                              |
| --------------- | --------------------------------------------------------- | ------------------------------------------------------------------------ |
| 로비            | 현재 연승 크게, 최고 연승 작게, 중앙 캐릭터, 큰 대전 시작 | 4종 빠른 선택, 캐릭터 선택 진입, 조작 안내, 매칭 취소                    |
| 캐릭터          | 무기·실루엣, 유형·전투 방식, 8개 키 설명                  | 선택 즉시 외형·이름·기술표 갱신, 선택 후 로비 복귀                       |
| 전투            | 양쪽 체력·궁극기, 중앙 시간, 경기장, 기술 바              | QWER 위·ASDF 아래, F 대상 상태, R 준비·소비, 기상·재접속 잠금, 기권 확인 |
| 결과            | 승패, 확정 연승, 계속 도전·쉬기                           | 기본 자동 매칭 꺼짐, 선택한 경우 5초 뒤 매칭·취소, 저장 대기·실패 처리   |
| 로그인·회원가입 | 이메일·비밀번호, 가입 시 닉네임, 게스트 진입              | 로그인/가입 전환, 브라우저 입력 검증, 실제 전송 없는 안내                |

`로비 → 선택 → 로비 → 대전 찾기 → 상대 배정 → 3초 준비 → 전투 → 결과 → 계속 도전 / 쉬기` 흐름을 예시로 연결합니다. 검색 대기는 목업용 고정 시간으로 짧게 재현합니다. 실제 네트워크와 매칭이 동작하는 것은 아닙니다.

## 4. 전투 UI 기준

- 조작은 A 유지형 웅크려 막기, S 대시, D 기본 공격, F 쓰러진 상대 추가 공격, Q/W/E 기본 스킬, R 궁극기입니다. 이전 키 배치는 사용하지 않습니다.
- F는 다운 상대가 있고 사용 가능한 상황에서 테두리·문구로 강조합니다. 서 있는 상대는 대상이 아니며, KO된 상대를 계속 공격하는 표현을 하지 않습니다. 실제 구현에서는 서버의 대상·회차·거리·벽·쿨다운 조건을 따라야 합니다.
- R은 100% 미만에 비활성 상태와 퍼센트를 표시합니다. 100%에 준비를 강조하고 수동으로 눌러 사용하면 0%로 갱신합니다. 일반 쿨다운 초로 표시하지 않습니다.
- 새 경기 시작은 0%입니다. 전투 탭의 기본 68%는 경기 중간 HUD를 보여 주는 예시이고, 매칭 흐름으로 진입하면 0%로 시작합니다.
- 다운·기상 중 행동 잠금과 게이지 준비를 구분합니다. 기상 중 100%여도 R 발동 가능 표시를 하지 않습니다. 목업에서는 기상·연결 종료 상황을 상태 선택으로 확인합니다.
- 재접속 중에는 경기가 계속된다는 문구와 입력 제한을 보여 줍니다. 서버 시간·HP가 실제로 진행되는 구현 검증은 별도입니다.
- 메뉴를 열어도 전투가 멈추지 않는다는 설명을 표시합니다. 기권은 연승 종료를 안내하고 확인 후 결과 화면으로 이동합니다.
- 궁극기 계수·다운 지속·기상·회차당 F 제한은 [전투 명세](COMBAT_CONTROLS.md)의 검수안을 따릅니다. 목업의 버튼 클릭은 UI 상태 변화이며 전투 시뮬레이터가 아닙니다. HP·피해·실제 판정·쿨다운 계산을 검증하는 용도로 사용하지 않습니다.

## 5. 연승·결과·오류 UX

- 승리 시 확정된 `4연승`과 계속 도전·쉬기를 함께 보여 줍니다. 쉬기 후 로비에서도 같은 연승을 보여 줍니다.
- 패배·무승부는 연승 종료를 표시하고 최고 기록은 보존합니다. 무승부의 연승 종료 정책은 기존 PRD의 검수안을 따릅니다.
- 자동 매칭은 기본 해제입니다. 켠 경우에만 5초 카운트다운을 표시하며 체크 해제·화면 이탈 때 취소합니다. 자동 매칭을 켜지 않아도 계속 도전을 누를 수 있습니다.
- 저장 중·실패 때 연승 확정을 먼저 표시하지 않습니다. `기록 확인 중`, 다음 대전 제한, 재시도 동작을 보여 줍니다. 네트워크 저장·정산의 실제 성공을 재현한 것이 아닙니다.
- 로그인 폼은 실제 가입·인증·메일 전송을 하지 않습니다. 계정 연결·연승 영속 저장은 기존 개발 과제로 남아 있습니다.
- 모달은 닫기·Escape·키보드 포커스 순환을 지원합니다. 예고 없는 화면 흔들림·점멸·반복 애니메이션·자동 음향은 넣지 않았습니다.

## 6. 화면 크기와 접근성

가로형 PC를 우선합니다. 1,024px 전후에서 로비 3열, 760px 이하에서 2열과 4종 선택 줄, 520px 이하에서 세로 배치를 사용합니다. 최소 320px를 대상으로 줄바꿈과 화면 내 조작 배치를 설계합니다. 작은 화면에서는 캐릭터 설명을 세로로 쌓고 전투 기술 바 아래에 궁극기 패널을 둡니다.

모바일 터치 전투 조작은 이번 범위에 없습니다. 작은 폭에서도 기획을 확인할 수 있도록 대응하는 것이며 방향키·QWER/ASDF 게임을 모바일에서 플레이할 수 있다는 뜻은 아닙니다.

주요 행동은 최소 44px 높이, 상태 글자는 최소 11px를 기본으로 합니다. 키보드 포커스 테두리, 실제 버튼·입력·탭·레이블·진행 수치, 변경 안내를 제공합니다. 실제 제품에서는 키보드 전용 탐색·대비·확대·스크린리더를 추가 검증합니다.
