# F08 — 로비·결과·휴식 UI

- 브랜치: `feature/lobby-ui`
- 우선순위: P0
- 상태: 기본 화면 구현, 실제 계정·정산·대기열 흐름 연결 미완료
- 기준: `bfe35d3`, [PRD](../PRD.md) 5·7절
- 선행 기능: F02, F04, F05, F06, F07, [기능 목록](README.md)

## 목표와 현재 상태

사용자가 지금 대기·전투·결과 저장 중 어느 단계인지 이해하고, 승리 후 계속하거나 연승을 보존하고 쉴 수 있게 합니다. 게임 메뉴를 일시정지로 오해하지 않게 합니다.

현재 `App.tsx`에 닉네임, 메모리 통계, 대전 찾기, HUD, 결과·기권 메뉴가 있습니다. 실제 DB 로딩·저장 오류·순위표 진입·승리 후 자동 매칭 옵션·음량 설정은 완성되지 않았습니다.

## 화면과 동작

| 상태            | 필수 표시·행동                                                   |
| --------------- | ---------------------------------------------------------------- |
| 로비            | DB 프로필·현재/최고 연승·승패 수, 대전 찾기, 순위표, 설정        |
| 계정/통계 로딩  | 로딩 상태, 미조회 기록을 실제 0승처럼 확정 표시하지 않음         |

| 준비·카운트다운 | 상대 표시, 에셋 로딩·준비 상태, 시작 전 입력 안내                |
| 전투            | 양쪽 체력, 서버 기준 제한 시간, 현재 연승, 8개 쿨다운, 연결 상태 |
| 저장 중         | F06 확정 대기, 다음 경기·반복 정산 요청 차단                     |

스킬 바는 위 `Q W E R`, 아래 `A S D F`로 배치합니다. 캐릭터 구분은 색상과 내 플레이어 표식을 함께 사용합니다. PC 웹이 범위이며 모바일 터치 컨트롤은 제외합니다.

## 휴식·기권·자동 매칭 규칙

1. 결과 화면에서 아무 입력이 없으면 다음 경기를 시작하지 않습니다. 쉬기·로그아웃은 확정된 연승을 바꾸지 않습니다.
2. 경기 메뉴는 전투를 멈추지 않습니다. 명확한 안내와 기권 확인을 제공하며 기권의 패배·연승 종료 효과를 보여 줍니다.
3. 승리 후 자동 매칭 옵션은 기본 해제입니다. 켜져 있어도 저장 확정 후 5초를 기다리고 취소할 수 있습니다. 패배·무승부·무효에는 자동 적용하지 않습니다.
4. 자동 매칭 대기 중 쉬기·옵션 해제·로그아웃·컴포넌트 종료 시 타이머를 해제합니다. 클릭과 타이머가 경쟁해도 참가 요청은 한 번만 발생합니다.
5. 명확한 서버 결과가 없으면 승리 배너·증가한 연승을 먼저 보여 주지 않습니다. 실패 시 같은 경기 저장 재시도와 로비 상태를 구분합니다.
6. 기본 음량·음소거는 로컬 설정에 저장합니다. 실제 오디오 재생·에셋은 F10이 제공하며 화면 클릭 후 브라우저 재생을 시작합니다.

## 상태·데이터 계약

- 인증·프로필·통계·대기열·전투·연결·정산 상태를 분리해 하나의 `participating` 값에 모두 의존하지 않도록 정리합니다.
- 결과 표시의 기준은 F06 정산 영수증입니다. `Snapshot`의 전투 종료와 영구 저장 완료를 구분합니다.
- 취소·연속 클릭·비동기 응답 순서가 뒤바뀌어도 이전 경기 응답이 새 화면을 덮어쓰지 않도록 요청 세대와 경기 ID를 확인합니다.
- Canvas 입력 포커스와 폼 키 입력을 분리합니다. 키보드만으로 로비·설정·기권 확인을 사용할 수 있어야 합니다.
